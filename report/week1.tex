\chapter{Validate seed-case report} 

\begin{enumerate}
    \item Check whether any fields contain null values or values that fall outside the defined categories.

    \item Verify whether the content of the prompt accurately aligns with the defined categories.
\end{enumerate}

\textbf{Limitation}

\begin{itemize}
    \item Some fields are self-defined: neutral communitation style and ambiguity level, both fields are semantic judgments
\end{itemize}
